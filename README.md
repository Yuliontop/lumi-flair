# Lumi Flair v1.0.0 — let the story control the room ✦

The first public release of Lumi Flair for Lumiverse.

**Install:** Extensions → Add Extension → paste `https://github.com/yuliontop/lumi-flair`

## Highlights
- **Atmosphere:** ambient snow, rain, embers, fireflies, petals and stars; cinematic lighting with lightning; procedural soundscapes (no audio files)
- **Flair Packs:** 8 one-click looks that can also restyle Lumiverse's theme, including **Character Aware**, which follows whoever is speaking
- **Your own packs:** Save my look, plus import and export `.flair.json`
- **AI storytelling:** expressive text effects (pick the ones you like), Scene Director tags, screen effects and choice chips
- **Glow & colour:** send effects, hover glow, mood-reactive colour, character auras, time-of-day tint
- **Story heartbeat:** your chat's emotional arc; click any point to jump there, even far back
- **Moment Cards, achievements, celebrations**
- **Comfort:** auto-saved settings with backup, battery saver, reduced motion, a no-flash mode, and 5 translations

Both permissions (`interceptor` for AI storytelling, `app_manipulation` for theming) are optional and requested only when you turn those features on.
