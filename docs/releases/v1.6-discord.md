# Lumi Flair v1.6 — Audio Visualizer 🎵

Bars that move to your music. In the desktop app, they dance to **whatever your computer is playing**.

## 🎵 Visualizer
Flair panel → **Audio visualizer**. A draggable floating window, a background layer behind the chat, and strips beside it. Use any or all. 4 styles, 🪞 **Center Mirror**, colours that follow your Flair Pack. Desktop only.

## 🔊 Sources
Flair's own sound • **this computer's sound** (desktop app) • a shared tab • microphone • demo

## 🖥️ Turn on "This computer's sound"
Needs the Lumiverse **desktop app** (updated; Windows 10+, macOS 14.2+, or Linux with PulseAudio/PipeWire).
1️⃣ Update Lumiverse. Tray menu → **Check for Updates**, or **Rebuild Desktop App…** if asked
2️⃣ Update Lumi Flair (Extensions → **Update**), then Ctrl+Shift+R
3️⃣ **Tray menu → tick "Let Extensions Analyse System Audio"** → Allow
4️⃣ Flair panel → Audio visualizer → **Show the visualizer** → **Listen to: This computer's sound**
5️⃣ Press **Connect audio** and allow both prompts
6️⃣ Play music 🎶

🍎 macOS: allow **System Audio Recording** (not Screen Recording)
🐧 Linux: needs `parec` (`pulseaudio-utils`)
❓ "Needs the desktop app"? Update/rebuild the app, then Ctrl+Shift+R

## 🔒 Privacy
Flair only gets a level and a spectrum, never the sound. Nothing is recorded. Lumiverse asks every time, shows a "listening" pill with **Stop**, and you can switch it all off in the tray.
